# Data

This project uses the PhonePe Pulse dataset for analyzing digital payment
transactions, users, device usage, and demographic information.

## Dataset Contents

The analysis uses the following datasets:

- State Transaction & Users
- State Transaction Split
- State Device Data
- District Transaction & Users
- District Demographics

## Analysis Areas

- Transaction trends
- User and transaction analysis
- Transaction type analysis
- Device-brand adoption
- District-level analysis
- Demographic analysis
- Population density
- Data-quality validation

## Data Source

PhonePe Pulse dataset.

The raw dataset is not included in this repository. The analysis notebook
contains the complete analysis workflow and can be run after providing
the required input data.
